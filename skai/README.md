# SkaiBOT — nouveau code

Ce dossier accueillera les développements propres à SkaiBOT (le socle réutilisé est dans `agent/` et `base-game/`).

Planifié (voir ../docs/ROADMAP.md) :
- `env_selfplay.py`        : entraînement de l'IA contre elle-même
- `env_speedrun.py`        : récompense "vitesse" + mode 400 tribus / 0 nation
- `train_selfplay.py`      : lancement de l'entraînement self-play
- `play_vs_human.py`       : 1v1 contre un humain sur partie locale
- `replays/`               : imitation à partir de tes replays
